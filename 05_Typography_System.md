## 6. TYPOGRAPHY SYSTEM

### 6.1 Font Families

#### Primary Font (Headings & UI)
**Font**: Inter or SF Pro Display
**Characteristics**: Modern, clean, excellent readability
**Usage**: Headings, buttons, navigation, UI elements
**Weights**: 400 (Regular), 500 (Medium), 600 (Semibold), 700 (Bold)

#### Secondary Font (Body Text)
**Font**: Inter or SF Pro Text
**Characteristics**: Optimized for body text, high legibility
**Usage**: Paragraphs, descriptions, form labels
**Weights**: 400 (Regular), 500 (Medium)

#### Monospace Font (Technical)
**Font**: JetBrains Mono or Fira Code
**Usage**: Bid IDs, transaction hashes, quantum signatures
**Weight**: 400 (Regular)

---

### 6.2 Type Scale

#### Desktop Typography

**H1 - Page Titles**
- Font size: 48px
- Line height: 56px (1.167)
- Weight: 700 (Bold)
- Letter spacing: -0.5px
- Usage: Main page headings, hero titles
- Example: "Welcome to QTrustBid"

**H2 - Section Headings**
- Font size: 36px
- Line height: 44px (1.222)
- Weight: 700 (Bold)
- Letter spacing: -0.25px
- Usage: Major section titles
- Example: "Featured Properties"

**H3 - Subsection Headings**
- Font size: 28px
- Line height: 36px (1.286)
- Weight: 600 (Semibold)
- Letter spacing: 0px
- Usage: Card titles, modal headings
- Example: "Property Details"
