# QTrustBid Design System - Part 10
## Detailed User Journeys & Flows

---

## 11. USER JOURNEY MAPS

### 11.1 Buyer Journey: First Property Search to Bid

#### Step 1: Landing & Authentication
**Entry Point**: Homepage or direct link
**Actions**:
1. User arrives at landing page
2. Clicks "Get Started" or "Browse Properties"
3. Prompted to login/signup
4. Completes authentication (AUTH-01 or AUTH-02)
5. Email verification (AUTH-06)

**Screens**: Landing → Login → Email Verification → Buyer Dashboard

**Duration**: 2-3 minutes

---

#### Step 2: Dashboard Orientation
**Entry Point**: BUYER-01 (Dashboard)
**Actions**:
1. Views welcome message and quick stats
2. Sees AI recommendations preview
3. Notices quantum-safe indicator
4. Optional: Views quantum security explainer (QS-01)
5. Clicks "Browse All Properties" or uses search

**Screens**: Dashboard → (Optional: Security Explainer) → Property Listing

**Duration**: 30 seconds - 2 minutes

---

#### Step 3: Property Search & Discovery
**Entry Point**: BUYER-02 (Property Listing)
**Actions**:
1. Applies filters (location, price, bedrooms)
2. Toggles AI Match Score filter
3. Browses property cards in grid view
4. Saves interesting properties to favorites (heart icon)
5. Clicks on property card to view details

**Screens**: Property Listing → Property Details

**Key Interactions**:
- Filter panel slide-in (mobile) or sidebar (desktop)
- Real-time results update as filters change
- Smooth card hover effects
- Instant favorite toggle with animation

**Duration**: 3-10 minutes

---

#### Step 4: Property Details Review
**Entry Point**: BUYER-03 (Property Details)
**Actions**:
1. Views hero image gallery (swipe/click through)
2. Reads property description
3. Checks AI Match Score and explanation
4. Reviews bid history timeline
5. Explores neighborhood insights
6. Views similar properties (AI-powered)
7. Decides to place bid

**Screens**: Property Details → Place Bid Modal

**Key Interactions**:
- Image gallery with smooth transitions
- Sticky "Place Bid" button on scroll
- AI Match Score tooltip on hover
- Map interaction for location
