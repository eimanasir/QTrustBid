## 7. COLOR PALETTE

### 7.1 Brand Colors

#### Primary Color - Quantum Blue
**Purpose**: Main brand color, primary actions, trust indicator
**Light Mode**:
- Primary 50: `#E3F2FD` (lightest, backgrounds)
- Primary 100: `#BBDEFB`
- Primary 200: `#90CAF9`
- Primary 300: `#64B5F6`
- Primary 400: `#42A5F5`
- Primary 500: `#2196F3` ← Main primary
- Primary 600: `#1E88E5`
- Primary 700: `#1976D2`
- Primary 800: `#1565C0`
- Primary 900: `#0D47A1` (darkest, text on light backgrounds)

**Dark Mode**:
- Primary 50: `#0D47A1` (darkest becomes lightest)
- Primary 500: `#42A5F5` ← Main primary (lighter for dark bg)
- Primary 900: `#E3F2FD`

#### Secondary Color - Trust Green
**Purpose**: Success states, verified badges, positive actions
**Light Mode**:
- Secondary 50: `#E8F5E9`
- Secondary 100: `#C8E6C9`
- Secondary 300: `#81C784`
- Secondary 500: `#4CAF50` ← Main secondary
- Secondary 700: `#388E3C`
- Secondary 900: `#1B5E20`

**Dark Mode**:
- Secondary 500: `#66BB6A` ← Lighter for visibility

#### Accent Color - Quantum Purple
**Purpose**: AI features, premium elements, highlights
**Light Mode**:
- Accent 50: `#F3E5F5`
- Accent 100: `#E1BEE7`
- Accent 300: `#BA68C8`
- Accent 500: `#9C27B0` ← Main accent
- Accent 700: `#7B1FA2`
- Accent 900: `#4A148C`

**Dark Mode**:
- Accent 500: `#CE93D8` ← Lighter variant
